- Adds an external Ed25519 witness receipt that detects coordinated rollback of the local keyring and audit log when the trusted receipt remains outside the local rollback boundary
- Adds a private keyring-plus-audit recovery bundle with per-member hashes, trusted-public-key comparison, external minimum-witness enforcement, and interrupted-restore rollback journaling
- Adds an integrity-inventoried recovery journal and signed offline startup preflight that automatically restores one valid interrupted transaction while blocking ambiguous or legacy state
- Authenticates the complete recovery transaction manifest with a dedicated private HMAC key and rejects missing, replaced, linked, or unsafe journal keys before live restore
- Adds status, target-bound private backup, pending-journal-verified restore, and atomic rotation for the recovery-journal HMAC key
- Adds an external validation evidence gate that distinguishes product failures from unavailable Docker or package index, managed browser policy, and missing customer scanner exports
- Binds mandatory JSON reports to zero child exit codes, report/log SHA-256 values, safe collector-owned output directories, bounded scanner corpus handling, and an independent evidence verifier
- Packages the exact source snapshot, signed request, requester public-key copy, and launch wrappers into a deterministic requester-signed runner kit with safe ZIP verification and extraction
- Pins one authorized operator Ed25519 identity inside the requester-signed challenge and rejects substitute operator keys before response creation or child execution
- Records the first verified response in a requester-signed hash-chain ledger and rejects replay or a conflicting second response for the same request
- Requires an independently retained requester-signed minimum checkpoint to reject a valid but older acceptance-ledger prefix before verification or receipt publication
- Maintains an append-only requester-signed checkpoint series so verification automatically uses the latest retained checkpoint head
- Moves checkpoint series through deterministic requester-signed transfer bundles and installs only monotonic same-chain extensions
