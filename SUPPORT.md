# Support

VulnFlow is a personal open-source portfolio project, not a commercial support service.

## Supported questions

Use GitHub Discussions or a normal issue for:

- installation problems that can be reproduced with the public repository;
- synthetic-data import or workflow questions;
- documentation corrections;
- reproducible defects in public functionality.

Include the operating system, Python version, exact command, sanitized logs, and a minimal synthetic reproduction.

## Not supported

- analysis of real customer or organizational vulnerability data;
- emergency incident response;
- production deployment guarantees or SLAs;
- recovery of damaged third-party systems;
- private consulting through public issues;
- requests to bypass authorization, policy, or disclosure rules.

Security vulnerabilities in VulnFlow itself must be reported privately through the process in [SECURITY.md](SECURITY.md).
