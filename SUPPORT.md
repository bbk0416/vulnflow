# VulnFlow Free — Public Beta support

VulnFlow is currently a free public beta. Support is **best-effort community/project support**, not a paid help desk, production SLA or emergency response service.

## Good public reports

Use GitHub issues for:

- reproducible installation or startup failures;
- scanner import/encoding/format compatibility problems;
- remediation/verification workflow defects;
- backup/recovery defects;
- usability friction that blocks the intended closeout workflow.

Include the VulnFlow version, operating system, Python version, launch method, reproduction steps and sanitized logs.

For scanner compatibility, use the dedicated issue template. Prefer synthetic reproduction data. If format fidelity matters, create the product's **sanitized/anonymized scanner diagnostic bundle** and review it before sharing.

## Do not publish

Do not attach or paste:

- real military, government, customer or company vulnerability data;
- internal hostnames, IP addresses, account identifiers or personal information;
- credentials, API tokens, private keys or session data;
- confidential scanner exports;
- vulnerability details about VulnFlow itself that require coordinated disclosure.

Security vulnerabilities in VulnFlow must follow [SECURITY.md](SECURITY.md).

## Not currently offered

- paid technical support;
- guaranteed response time;
- production deployment guarantee or SLA;
- emergency incident response;
- private consulting through the public repository;
- recovery of unrelated third-party systems.

A future commercial subscription may introduce a separate support offering. It does not exist yet. See [PRODUCT_EDITION_POLICY.md](PRODUCT_EDITION_POLICY.md).
