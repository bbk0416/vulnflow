# Support

VulnFlow is a personal open-source portfolio project, not a commercial support service or a continuously staffed public support queue.

## Public repository scope

The public repository is maintained for reproducible portfolio review. Public issue creation or Discussions may be restricted. When contribution controls allow it, use a pull request for:

- documentation corrections;
- minimal fixes for reproducible defects in public functionality;
- improvements that use only synthetic data and preserve the documented project scope.

Include the operating system, Python version, exact command, sanitized logs, and a minimal synthetic reproduction in the pull request description.

## Not supported

- analysis of real customer or organizational vulnerability data;
- emergency incident response;
- production deployment guarantees or SLAs;
- recovery of damaged third-party systems;
- private consulting through the public repository;
- requests to bypass authorization, policy, or disclosure rules.

Security vulnerabilities in VulnFlow itself must be reported privately through the process in [SECURITY.md](SECURITY.md).
