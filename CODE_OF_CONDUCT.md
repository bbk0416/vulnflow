# Code of Conduct

VulnFlow contributors and participants are expected to keep technical discussion respectful, evidence-based, and focused on improving the project.

## Expected behavior

- Critique code and decisions, not people.
- Explain security claims with reproducible evidence.
- Respect privacy and never request or publish real vulnerability data, credentials, or personal information.
- Clearly separate verified behavior from assumptions, proposals, and untested claims.
- Give credit for contributions and accept correction when evidence changes.

## Unacceptable behavior

Harassment, discriminatory language, threats, doxxing, deliberate publication of sensitive security data, and repeated bad-faith disruption are not accepted.

## Enforcement

Maintainers may edit, hide, close, or remove content and participation that violates this policy. Sensitive security concerns should be reported privately according to [SECURITY.md](SECURITY.md).
