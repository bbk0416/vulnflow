# 방법과 제한

## 점수 구성

- **위협 신호:** KEV, CVSS, EPSS
- **자산 맥락:** 인터넷 노출, 자산 중요도, 데이터 민감도
- **조치 긴급성:** 패치 가능, 보완통제, 활성 항목의 기한 초과

점수와 하위점수, 근거 문장을 함께 저장합니다. KEV와 인터넷 노출이 동시에 확인되면 즉시 조치 규칙을 우선합니다.

## SLA

정책 목표일은 최초 평가일에 고정됩니다. 사용자가 입력한 운영 목표일이 있으면 대시보드와 기한초과 판정에서 우선 사용합니다.

## 위험수용

operator는 만료일과 사유를 포함한 승인 요청을 생성합니다. approver 또는 admin이 승인·반려하며 승인자는 인증된 사용자 이름으로 기록됩니다. 요청 이후 항목이 변경되면 행 버전 충돌로 승인을 차단합니다. 만료된 위험수용은 유지관리 작업에서 OPEN으로 재개방합니다.

이 흐름은 판단과 책임 소재를 기록하기 위한 것이며 실제 조직의 공식 권한 위임, 법률 검토, 전자서명을 대체하지 않습니다.

## 보존정책

보존기간이 0이 아니면 오래된 일반 감사·가져오기 이력을 삭제할 수 있고, 오래된 STALE 항목을 ARCHIVED로 전환할 수 있습니다. 조직의 감사·법적 보존 요구를 확인한 뒤 설정해야 합니다.

## 검증 제한

합성 정책 시험은 규칙이 의도대로 동작하는지와 가중치 변화에 대한 순위 안정성을 확인합니다. 실제 공격, 실제 사고, 실제 조치시간을 예측하거나 입증하지 않습니다.
