# VulnFlow 72.0.25

기본 프로젝트 운영 데이터와 사용자·프로젝트 권한을 보관하는 제어 데이터를 별도 SQLite 파일로 분리하고, 복구 번들을 프로젝트 정체성에 결합한 안전성 릴리스입니다.

## 주요 변경

- `data/control.db`에 사용자, 세션, 프로젝트 등록정보와 멤버십을 보관
- 기본 프로젝트 데이터를 `data/projects/default/vulnflow.db`로 분리
- 72.0.24 이하 단일 DB를 두 저장소로 SQLite backup API를 통해 보존 마이그레이션
- 구형 DB와 기존 증거·내보내기·미리보기·복구 디렉터리를 삭제하지 않고 기본 프로젝트로 복사
- 완료된 마이그레이션에서 구형 디렉터리를 반복 복사하지 않도록 방지
- 복구 번들 format v2에 `project_id`, `project_name`, `database_role` 추가
- 다른 프로젝트 복구 번들 및 정체성 없는 구형 번들의 무의식적 복원을 차단
- 공개 pytest 실행기가 출력 문자열로 성공을 추정하지 않고 실제 종료 코드와 정확한 수집 건수를 사용
- Docker build context에서 `.env`, 운영 DB, 증거·백업, 개인키와 초기 자격증명을 제외
- Dockerfile의 `COPY . .` 제거 및 필요한 애플리케이션 파일만 명시적으로 복사
- Windows·Linux 실행 시 Python 3.12·3.13만 허용하고 저장소 분리 준비 후 제어 DB에 최초 관리자를 생성
- 공개 핵심 회귀시험을 347개로 확대
- SQLite table schema 44 유지

## 업그레이드 주의사항

첫 실행 전에 현재 `data/` 디렉터리 전체를 별도 위치에 복사해야 합니다. 자동 마이그레이션은 기존 `data/vulnflow.db`를 삭제하지 않지만, 운영 복구 절차가 변경되므로 새 제어 DB와 기본 프로젝트 DB가 모두 생성됐는지 확인한 뒤 서비스를 개방해야 합니다.
