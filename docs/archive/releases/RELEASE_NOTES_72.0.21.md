# VulnFlow 72.0.21

파일럿 고객이 설치 직후 무엇을 설정해야 하는지 한 화면에서 확인할 수 있도록 온보딩과 고객용 보고 기능을 추가한 릴리스입니다.

## 주요 변경

- 프로젝트별 고객사·프로젝트 정보 저장
- 필수·권장 운영 준비 체크리스트
- 사용자, 무결성, 백업, 복원 리허설, 데이터 입력, 협업 연동, HTTPS 상태 통합 점검
- 프로젝트별 준비도 JSON API
- 고객사명·진단 범위·담당자·조치 현황이 포함된 인쇄형 경영진 HTML 보고서
- 프로젝트별 프로필 물리 분리
- SQLite schema 43 → 44 업그레이드
- 324개 공개 회귀시험을 5개 프로세스로 실행하고 종료 지연 자원을 정리하는 bounded runner

## 운영 참고

필수 준비 항목은 프로젝트 정보, 사용자 배정, 데이터 무결성, 복구 가능한 백업입니다. 실제 스캐너 데이터, 복원 리허설, 이메일·Jira, HTTPS는 권장 항목으로 별도 표시합니다.
