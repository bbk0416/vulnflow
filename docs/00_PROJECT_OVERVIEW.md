# 프로젝트 개요

## 해결하는 문제

취약점이 다수 식별된 환경에서는 CVSS만으로 실제 조치 순서를 설명하기 어렵고, 반복 스캔에서 항목이 새로 생겼는지·계속 존재하는지·사라졌는지 추적하기도 어렵습니다. 담당자·기한·완화조치·위험수용 결정이 여러 문서에 흩어지면 감사 가능성도 낮아집니다.

VulnFlow는 스캐너·원천별 취약점 데이터와 위협정보·자산 맥락을 결합해 검토 순서를 제시하고, 신규·갱신·STALE·ARCHIVED 생명주기와 조치 운영, 위험수용 승인, 유지관리를 같은 로컬 데이터베이스에서 관리합니다.

## 사용자와 역할

- viewer: 조회와 보고서 내보내기
- operator: 취약점 가져오기, 조치 운영, 위험수용 요청
- approver: operator 권한과 위험수용 승인·반려
- admin: 백업·복원·초기화·유지관리 포함 전체 권한

## 범위

- 식별된 취약점의 우선순위·조치 운영
- 스캐너·원천별 증분/전체 스냅샷 대조
- 로컬 또는 제한된 내부망 실행
- DB 기반 사용자 로그인 세션·Bearer API 토큰과 역할 분리
- 공개 위협정보와 CSV 기반 입력
- 위험수용 요청·승인·만료 재개방
- 보고·감사·백업·복원·보존정책
- HMAC 웹훅 아웃박스와 요청 추적·기본 메트릭

취약점 스캐닝, 자산 자동 발견, 실제 영향 여부 자동 확정, 중앙 IAM·MFA, 다중 조직 테넌시는 범위 밖입니다.
