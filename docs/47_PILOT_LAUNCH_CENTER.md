# 파일럿 시작 센터

VulnFlow 72.0.32은 새 고객사 프로젝트를 만든 뒤 필요한 설정과 운영 준비 상태를 한 화면에서 확인합니다.

## 접근

관리자 계정으로 로그인한 뒤 `관리자 메뉴 → 파일럿 시작 센터`를 엽니다. 모든 정보는 현재 선택한 프로젝트 DB에 저장되므로 다른 고객사 프로젝트와 섞이지 않습니다.

## 프로젝트 정보

다음 값은 고객용 경영진 보고서에 사용됩니다.

- 고객사 이름
- 프로젝트·진단 이름
- 고객 담당자와 이메일
- 기본 조치기한
- 진단 범위와 전제
- 보고서 하단의 배포 제한·문의 문구

프로필 변경은 감사 이벤트 `PILOT_PROFILE_UPDATED`로 기록됩니다.

## 준비도 판정

필수 항목은 다음 네 가지입니다.

1. 고객사·프로젝트 정보
2. 프로젝트 사용자 배정
3. 프로젝트 데이터 무결성 정상
4. 로컬 또는 외부 복구 번들 존재

권장 항목은 스캐너 데이터 입력, 격리 복원 리허설, 이메일 또는 Jira 연동, HTTPS URL과 Secure 쿠키입니다. 권장 항목이 미완료여도 시작 가능으로 표시될 수 있으므로 실제 운영 책임자는 배포 환경에 맞게 별도로 승인해야 합니다.

## 경영진 보고서

`경영진 보고서 받기`는 현재 프로젝트의 프로필과 취약점 스냅샷을 HTML 파일로 생성합니다. 보고서에는 상태별 건수, 기한 초과, KEV, 인터넷 노출, 조치 우선순위와 상위 활성 항목이 포함됩니다.

보고서는 생성 시점 스냅샷이며 다음을 보장하지 않습니다.

- 취약점의 실제 악용 가능성 확정
- 고객 조직의 최종 위험 승인
- 완전한 규제 제출 양식
- 원본 스캐너 결과의 정확성

## API

인증된 프로젝트 사용자는 다음 읽기 API로 준비 상태를 확인할 수 있습니다.

```text
GET /api/v1/pilot-readiness
```

API 응답은 현재 선택된 프로젝트의 프로필과 체크리스트만 반환합니다. 비밀번호, API 토큰, 암호문 등 비밀정보는 포함하지 않습니다.

## 스키마 업그레이드

schema 44는 `pilot_project_profile` 단일 행 테이블을 추가합니다. 기존 schema 43 프로젝트 DB는 시작 시 자동으로 44로 올라가며 기존 취약점·증거·협업 설정은 유지됩니다.
